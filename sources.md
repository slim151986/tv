# Источники и проверка `t.m3u`

Проверка проведена 14 ноября 2026 года без авторизации. Для каждого URL проверялись HLS-манифест и до двух актуальных медиасегментов. Сегменты читались ограниченным объёмом данных; длительный просмотр FFmpeg не выполнялся в рамках этого этапа. У всех семи пунктов нет AES-шифрования в проверенном манифесте. Это не подтверждает права на конкретный поток.

Источник каталогизации — [IPTV-org: русские потоки](https://github.com/iptv-org/iptv/blob/master/streams/ru.m3u) и подсписок [Televizor24](https://github.com/iptv-org/iptv/blob/master/streams/ru_televizor24.m3u). Для пункта 01 также использовалась запись из локального проекта. URL из `ru_televizor24.m3u` ниже проверен как содержащий варианты нескольких качеств; каждый пункт отдельно проверен на HTTP-доступность сегментов.

Все семь оставлены для ручного сравнения, хотя доступность сегментов — лишь краткая проверка, а не гарантия стабильности или совместимости с Orsay.

## Исключённые кандидаты

| Кандидат | Причина исключения |
|---|---|
| `http://31.148.5.241/kanal_1/index.m3u8` | Манифест и первый сегмент доступны, второй сегмент завершился таймаутом; нестабильность подтверждена уже на короткой проверке. |
| `http://streaming.televizor-24-tochka.ru/live/4.m3u8` | HTTP 403. |
| `http://31.148.48.15/Pervii_kanal_HD/index.m3u8` | Таймаут соединения. |
| `https://edge1.1internet.tv/dash-live2/streams/1tv-dvr/1tvdash.mpd` | Это DASH, а не HLS; проверка TLS завершилась таймаутом. |
| Запись NGENIX/Zabava из публичного каталога | Каталог помечает её как geo-blocked; не включена в открытый тестовый плейлист. |
| `https://1tv.ru` (официальная страница) | Официальная страница доступна, но статический публичный M3U8 для прямого воспроизведения не обнаружен. Скрытые API/защищённые варианты не извлекались. |
| `http://1tvcrimea.ru/1tvcrimea.m3u8` | Это отдельный региональный канал, не федеральный Первый канал. |
| Неоднозначный `a3569458063-s26881.cdn.ngenix.net/.../russia_hd/...` | В стороннем списке метка указывала «Первый канал», но путь/название указывает на иной канал; не включён из-за несоответствия идентичности. |

Публичная запись каталога не исключает, что поставщик использует ограничения подписки, географии или права третьей стороны. Явные признаки геоблокировки/ошибки доступа исключены; неочевидные условия доступа по конкретным URL не подтверждены. Проверяйте и используйте потоки только если у вас есть право доступа в вашей юрисдикции.
