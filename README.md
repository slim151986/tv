# Samsung Orsay test playlists

Публичные статические M3U-файлы для ручного испытания на Samsung Orsay с OTT-play FOSS.

- Постоянный тестовый список Первого канала: <https://slim151986.github.io/tv/t.m3u>
- Будущий основной список с двумя подтверждёнными на телевизоре каналами: <https://slim151986.github.io/tv/1.m3u>
- Статусная страница: <https://slim151986.github.io/tv/>

Текущая метка сборки `stage4-r2-2026-11-14`. В тестовом списке сохранён №07 — он воспроизводился на Android, но не запустился на Samsung. Новых независимых открытых HLS-источников, прошедших проверку манифеста и сегментов, в этой итерации не найдено, поэтому №08 не добавлен. Предыдущие №01–06 удалены из текущего тестового списка.

Адрес `t.m3u` постоянный: содержимое можно менять коммитом в `main`, URL на телевизоре вводить повторно не нужно. Для проверки обновления перезапустите OTT-play и откройте сохранённый источник ещё раз. Если новые строки не видны, проверьте категорию «Все»: [FAQ OTT-play FOSS](https://ottp.eu.org/www/faq/) предупреждает, что при изменении фильтра категорий новые каналы могут отображаться только там.

GitHub Pages раздаёт только текст плейлиста. Видео загружается OTT-play напрямую с указанного внешнего сервера. GitHub не ускоряет видео и не устраняет фризы. Компьютерная проверка не гарантирует совместимость Orsay. Все внешние ссылки получены из открытых каталогов; публичная запись и техническая доступность не подтверждают права на конкретную ретрансляцию. Подробности текущего набора указаны в [sources.md](sources.md).
