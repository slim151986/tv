# Samsung Orsay test playlists

Публичные статические M3U-файлы для ручного испытания на Samsung Orsay с OTT-play FOSS.

- Тестовый список вариантов Первого канала: <https://slim151986.github.io/tv/t.m3u>
- Будущий основной список с двумя подтверждёнными на телевизоре каналами: <https://slim151986.github.io/tv/1.m3u>
- Статусная страница: <https://slim151986.github.io/tv/>

Адрес `t.m3u` постоянный: новые тестовые наборы публикуются обычным изменением файла в `main`; вводить URL повторно не нужно. Внутри `t.m3u` есть метка сборки, по которой можно заметить обновление и обновить список в OTT-play, если приложение кеширует его.

GitHub Pages раздаёт только текст плейлиста. Видео загружается OTT-play напрямую с указанных внешних серверов. Хостинг M3U на GitHub не ускоряет исходные серверы и не устраняет фризы. Работоспособность URL и FFprobe на компьютере не гарантируют совместимость с Orsay; итоговая проверка проводится на телевизоре. Старый Orsay также может не поддерживать TLS-настройки GitHub Pages.

Ссылки собраны из открытых каталогов. Наличие в открытом каталоге и техническая доступность сами по себе не подтверждают разрешение правообладателя на конкретную ретрансляцию. Для каждого пункта источник и известный результат проверки перечислены в [sources.md](sources.md).
